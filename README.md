# Building an LLM From Scratch

A personal project focused on understanding and implementing the core concepts behind Large Language Models (LLMs) from the ground up.

The goal is to explore the mathematics, architectures, and mechanisms that power modern language models by implementing them step by step, rather than relying on high-level deep learning frameworks.
